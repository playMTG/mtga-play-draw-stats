---

## 一句话定位

从「先后手统计表」变成「以套牌／主将为中心的复盘助手」：  
玩家每天只打 5～10 局，产品要替他**在小样本里说人话、抓住值得说的点**，并把多日同一套牌的记录**串成旅程**，而不是再堆一列对局表格。

---

## 产品原则（来自 2026-09-10 使用反馈）

1. **小样本也要敢说亮点**  
   当天 5 场 4 胜，就是「今天胜率亮眼」；后手 75% 就是「今天明显偏后手」。  
   样本小是事实，不是沉默理由——用数字说清楚「n 场里…」，比「资料不足，请积累更多」有用。  
   仍禁止编造日志没有的因果（操作、被针对）。

2. **少写无信息量的句子**  
   5 场遇到 5 个不同主将 → 不写。  
   5 场遇到 3 个阿耶尼 → 才写。  
   默认战报应能在一屏内读完；详情折叠，不是主路径。

3. **显示名要短、要对**  
   双面／转化牌只显示正面名称（拿卡地贱民阿耶尼，不写「// 拿卡地复仇者阿耶尼」）。  
   赛事名去掉冗余括号与过长后缀。  
   **已落地**：卡名层按 `//` 截断到正面，完整名与来源进展开详情（R4/R5，2026-09-09）；赛事名清理见 `event_names.py`（R3）。

4. **没有基线就不比**  
   「与此前 30 天比较」在无可比数据时整段隐藏；空壳对比没有意义。

5. **主路径是复盘，不是表**  
   对局明细仍是核对用底表；产品重心是「以套牌/主将为单位的历史串联」（对齐 Untapped 等工具的使用方式）。

6. **赛制差异必须承认**  
   争锋有主将；轮抓／现开是临时牌组。不能把争锋模板硬套到无主将赛制。

## 能力地图（R10 之后）

### V0 — 战报与命名打磨（小步，可先于 V1）

**状态：已完成（2026-09-11）** — 已随 R11.6 发版验收，见 v0.3.0。

- 重写每日一句话与亮点优先级（原则 1、2、4）。
- 卡名正面-only；赛事名清理。
- 空基线隐藏。
- 验收：用真实某日 5 场 4 胜、后手偏斜等样本人工读一遍，「一屏读完、只留有信息量的句子」。

### V1 — 套牌旅程（Deck Journey）

对局明细降级为「核对」；主路径：

```
套牌（或主将 / draft 临时牌组）
  → 时间轴：哪几天打了、胜率与先后手如何变化
  → 版本变更点：改构筑前后的战绩切片
  → 常遇对手（仅重复遭遇）
  → 单日亮点链接回每日战报
```

- 身份继续用现有 `my_deck_id` / 构筑指纹，不按显示名合并。  
- 轮抓：一次 draft = 一个临时身份，页头写清「本轮抓位套牌」，不套争锋主将栏。  
- 对齐物：Untapped 的 deck-centric 视图；本插件保持本地、可解释、小样本诚实。

**进度（2026-09-11）**：套牌详情含按日时间轴、构筑版本变更点、页头套牌类型（争锋／构筑／轮抓临时）；日轴日期可点，关闭详情并跳回该日每日战报；明细标题标为「核对用」。待做：更深的首页入口重构（V3 一并做赛制自适应）。

### V2 — 主将环境观察（前置讨论已写过，此处归档）

- 入口：主将点击 或 套牌详情 Tab（R10 后再定）。  
- 切片：遭遇分布 + 全库/其它主将基线 + 先后手 + 点选对手拆解。  
- 措辞：只描述偏离，不输出「被针对」。  
- 实现落点：`stats.py` 现算，不新表。

**进度（2026-09-11）**：已挂在套牌详情「主将环境」——我方主将、先后手、对手占比 vs 全库争锋基线、分先后手胜率；点选可回查对局。另：每日评语增加「高场次肝度」优先（≥15 耐力局），压过普通三连/五五开胜率。

### V3 — 赛制自适应信息架构

- 争锋：主将、镜像、CommandZone。  
- 轮抓/现开：抓位、色组、临时套牌、单次复盘；隐藏主将栏。  
- 排位：段位曲线与先后手并重。  
- 首页信息密度随「最近主赛制」调整，而不是永远以争锋为默认模板。

**进度（2026-09-11）**：`stats.format_focus` 按近 30 天主赛制给出 `show_commanders/show_rank/show_opponent_types`；首页提示条 + 收放对手主将/段位/构筑类型区块；排位焦点时段位曲线上移。套牌详情已含 `deck_kind`（争锋/构筑/轮抓临时）。筛选后以筛选为准，不强行收放。

## 建议节奏

1. **先做完 R9—R10**（ROADMAP 原序），不因本文打断。  
2. R10 验收后，用一次真实「周复盘」体验验收：  
   - 每日是否更短更有亮点  
   - 是否想点进套牌看多日变化  
3. 若答案是「想看套牌旅程」→ 启动 **V0 + V1**；主将环境 **V2** 作为 V1 的插件 Tab。
